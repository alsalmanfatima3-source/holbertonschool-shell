# Shell, I/O Redirections and Filters

This project contains Bash scripts for practicing input/output redirections and text processing commands.

## Scripts

- `0-hello_world`: Prints "Hello, World" followed by a new line.- `2-hellofile`: Displays the content of the /etc/passwd file.- `3-twofiles`: Displays the content of /etc/passwd and /etc/hosts.- `5-firstlines`: Displays the first 10 lines of /etc/passwd.- `6-third_line`: Displays the third line of the iacta file using head and tail.
